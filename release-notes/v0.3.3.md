**Fixes**
- **Recycle Bin display**: Items moved to the Recycle Bin no longer deceptively display as `0 KB freed`. The results screen and share card now explicitly show `{size} moved to Recycle Bin`, and update correctly once the bin is emptied.
- **Empty Recycle Bin directly**: Added an inline button on the completion screen to empty the Recycle Bin immediately without leaving the app.

**Documentation & Web**
- Deployed official static landing page via GitHub Pages (`landing/`).
- Updated README badges, screenshots, and direct release links.

**Update:** if you have 0.2.1 or later, DiskBreeze offers this update when it starts. Otherwise run `DiskBreeze_0.3.3_x64-setup.exe`, or unzip the portable build and run `diskbreeze.exe`. Verify with `SHA256SUMS.txt`. The app isn't code-signed yet, so Windows SmartScreen may warn: click *More info → Run anyway*.
