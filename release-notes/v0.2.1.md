**Fixes**
- **Bootable drives are left alone.** Big-file scanning could have offered the install file of a Windows installer USB stick (`install.wim`/`.esd`) once it was over 90 days old. Bootable media is now skipped entirely, and those file types are no longer offered.
- Cleaners that run a tool (npm, pnpm, Go…) now report how much they freed instead of "0".
- A drive with nothing to clean shows a friendly "Nothing to clean" screen.

**New**
- **Cleanup history:** a log of every cleanup (what, when, how much, and what failed), kept only on your computer. Open it from the *History* button; *Copy report* gives a text summary for bug reports.
- **Automatic updates:** DiskBreeze checks GitHub for a newer version when it starts and offers to install it. You always choose; nothing installs silently. Turn the startup check off on the start screen. This is the only network request the app makes.

**Install:** run `DiskBreeze_0.2.1_x64-setup.exe`, or unzip the portable build and run `diskbreeze.exe`. Verify with `SHA256SUMS.txt`. The app isn't code-signed yet, so Windows SmartScreen may warn: click *More info → Run anyway*. Versions before 0.2.1 can't update themselves, so install this one by hand.
