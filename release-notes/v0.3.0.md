**New: more of your disk, explained**
- **Windows system space (asks for administrator permission).** Downloaded Windows Update files, old Windows component versions, and the hibernation file can now be cleaned from inside the app. Windows shows its own permission prompt first; nothing runs unless you allow it, and none of these is ever pre-ticked. Every administrator command is fixed in the app, passed to Windows without writing a file, and pinned by a test.
- **Docker and WSL.** Shows what Docker could reclaim (unused images, stopped containers, build cache) when Docker is running; volumes are never touched. Also offers to shrink the disk files WSL and Docker Desktop keep, which grow but never shrink on their own, to give space back to Windows.
- **OneDrive "free up space".** Big files you haven't touched in a month can become online-only: the copy in OneDrive stays, and they download again when opened. Files you pinned are never listed.
- **Installed programs.** Your biggest programs, with an *Uninstall…* button that opens each program's own uninstaller.

**Honest numbers**
- Sizes that can't be known up front are shown as *up to* or *varies* and are kept out of the "can be cleaned" total.
- Cleanups that run as administrator report only what the drive really gained. In testing, clearing 7.4 GB of Windows Update files returned about 2.4 GB, because some of those files share disk space with others.

**Tested and not**
- Tested in the real app on Windows 11: the administrator permission step (allowing it works, declining changes nothing) and clearing the Windows Update downloads, including the history entry.
- Covered by automated tests and scans on a real machine, but **not yet run live**: the Docker prune commands (Docker was stopped), shrinking WSL/Docker disk files, the component-store cleanup, making OneDrive files online-only, and the uninstall buttons. They only ever run after you choose them and (where needed) allow Windows' prompt, but treat them as new.
