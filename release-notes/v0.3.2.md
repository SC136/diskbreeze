**Fix**
- **Opening the drive dropdown no longer blanks the window.** The pop-up list was being drawn on top of a full-window layer, so the app disappeared and clicks went nowhere. The same problem affected dialogs (confirm, history), which showed a blank page behind them. Fixed for all of them.

**New (thanks to [@Chronos778](https://github.com/Chronos778), PR #1)**
- **Search box** above the results: filter findings by name, category, description or path.
- **Copy report** button: a plain-text summary of a scan, handy for sharing or bug reports.
- **More cleanup targets:** JetBrains IDE caches, vcpkg binary cache, Unity package cache, Unreal Engine derived data, Adobe Media Cache, and iPhone/iPad backups (sent to the Recycle Bin, never pre-ticked).
- Contributor guide (`CONTRIBUTING.md`) and issue/PR templates.

**Also**
- *Select all / Select none* now only applies to the findings the search shows.
- A safety test now blocks catalog entries that point at folders holding installed programs. (One proposed entry would have emptied winget's portable-program folder, so it was left out.)

**Update:** if you have 0.2.1 or later, DiskBreeze offers this update when it starts. Otherwise run `DiskBreeze_0.3.2_x64-setup.exe`, or unzip the portable build and run `diskbreeze.exe`. Verify with `SHA256SUMS.txt`. The app isn't code-signed yet, so Windows SmartScreen may warn: click *More info → Run anyway*.
