**Fixes and polish**
- **A tidier update banner.** It shows one line and a *What's new* button instead of the whole release notes.
- **Your cleanup history now lives in the app's own data folder** instead of the install folder, so updating or uninstalling the app can't take it with it. An existing history log is moved over automatically the first time it's needed.

**Verified**
- In-app updating works end to end: an installed 0.2.1 found 0.3.0, downloaded it, checked its signature, installed it and relaunched, keeping the history log. This release is offered the same way to 0.3.0.

**Install:** if you have 0.2.1 or later, DiskBreeze offers this update when it starts. Otherwise run `DiskBreeze_0.3.1_x64-setup.exe`, or unzip the portable build and run `diskbreeze.exe`. Verify with `SHA256SUMS.txt`. The app isn't code-signed yet, so Windows SmartScreen may warn: click *More info → Run anyway*.
