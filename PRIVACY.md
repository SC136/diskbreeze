# Privacy policy

DiskBreeze runs entirely on your computer. It has no accounts, no analytics and no telemetry, and the developers collect no data about you or your files.

## What is stored on your computer

- **Cleanup history.** What was cleaned, when, how much space it freed, and whether it succeeded, including the paths involved. It is stored locally in your Windows app data folder and never uploaded. You can inspect it from *History* in the app.
- **App settings**, such as whether the update check is enabled.
- **Share cards**, only when you choose to save one, written to the folder you pick.

Deleting the app's data folder removes this information.

## Network requests

- **Update check.** When the app starts, it asks GitHub for the latest release metadata from `github.com/SC136/diskbreeze`. GitHub receives standard request information such as your IP address and user agent, subject to GitHub's privacy statement. No information about your files, disk or system is sent. You can turn this check off on the start screen.
- **Update download.** If you accept an update, the installer is downloaded from GitHub Releases.

That is the complete list. The app does not contact any other server, and nothing about your files ever leaves your computer.

## Third parties

- **GitHub** hosts the source code, releases and the update check. See the [GitHub privacy statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).
- **SignPath Foundation** provides code signing for release binaries. It receives only the built binaries, never data from your computer.
